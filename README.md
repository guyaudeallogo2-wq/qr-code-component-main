## Overview

The QR Code Component is a simple webpage displaying a QR code inside a
card, accompanied by a heading and a short description encouraging users
to scan it.

The objective was to reproduce the original design as closely as
possible while practising HTML structure and CSS styling.

## My Process

I started by creating the HTML structure before moving on to the CSS
styling.

After organizing the content, I used CSS Flexbox to align the elements
and worked on spacing, dimensions, typography, and other visual
properties to reproduce the original design.

### What I Learned

Working on this project helped me understand several fundamental
concepts in frontend development:

-   How to structure a webpage using HTML elements.
-   The difference between block, inline, and inline-block elements.
-   How CSS Flexbox works and how to use it for alignment.
-   How the CSS box model works, including margin, padding, and borders.
-   How to organize CSS rules and apply styles to specific elements.
-   How to use Git and GitHub to manage and publish a project.

One particularly useful lesson was understanding that Flexbox should be
applied to the parent container when you want to control the alignment
of its child elements.
